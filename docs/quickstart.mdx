---
title: Quickstart
description: Run an agent that looks up an order and tells you whether it has shipped.
---

This example connects an AI model to a small order lookup function. You need Docker,
Node.js 22 or newer, and an OpenAI API key. Model calls use your provider account.

Prefer hosting? Use the [Aex quickstart](/docs).

## 1. Start Brain

```sh
docker run --rm -p 127.0.0.1:8080:8080 \
  -e BRAIN_LISTEN=0.0.0.0:8080 -e BRAIN_API_TOKEN=quickstart \
  -v brain-data:/var/lib/brain ghcr.io/aexhq/brain:latest
```

Leave this terminal running. The Docker volume keeps your saved sessions between restarts.
The example token is for local use; choose your own token when deploying a server.

## 2. Install the client

In another terminal, create a project:

```sh
mkdir brain-example
cd brain-example
npm init -y
npm install @aexhq/brain@0.34.0 @aexhq/agentloop-pi@7.2.2 zod@4
```

Set your model key in this terminal:

```sh
export OPENAI_API_KEY="your-key"
```

In PowerShell, use `$env:OPENAI_API_KEY = "your-key"` instead. Keep keys out of source control.

## 3. Add a tool and send a message

Save as `order.mjs`. This JavaScript also works in TypeScript; the SDK infers tool arguments
from the Zod schema.

```js
import { Brain, brainEnv, tool } from "@aexhq/brain";
import { pi } from "@aexhq/agentloop-pi";
import { z } from "zod";

const lookupOrder = tool({
  name: "lookup_order",
  description: "Look up an order by id.",
  input: z.object({ id: z.string() }),
  run: ({ id }, ctx) => ctx.finish({ id, status: "shipped" }),
});

const brain = new Brain({ baseUrl: "http://127.0.0.1:8080", token: "quickstart" });
try {
  const session = await brain.sessions.create({
    model: { provider: "openai", name: "gpt-5-mini", apiKey: process.env.OPENAI_API_KEY },
    agentloop: pi({ env: brainEnv({ name: "brain" }) }),
    tools: [lookupOrder()],
  });
  try {
    await session.send("Look up order A-1001. Has it shipped?");
    console.log(JSON.stringify(await session.transcript(), null, 2));
    console.log("Session:", session.id);
  } finally {
    await session.end();
  }
} finally {
  await brain.close();
}
```

## 4. Run it

```sh
node order.mjs
```

The printed transcript includes a `lookup_order` result and an answer saying order A-1001
has shipped. The exact wording depends on the model. The function returns sample data;
replace it with a lookup in your own application.

`brainEnv` runs the ready-made loop on the Brain server. `hostEnv` runs your lookup function
in this Node process. Keep the process connected while its tools are needed. `ctx.finish(value)`
returns the result and marks the tool complete.

The example ends the conversation but keeps its history. To keep chatting in the same run,
add another `session.send(...)` before `session.end()`.
