---
title: Write an Agentloop
description: Implement the WIT contract, supply raw Component bytes, and place the Agentloop.
---

Brain does not compile Agentloop source. Write the loop in any language that can produce a
WebAssembly Component implementing Brain's WIT world, build it with that language's toolchain, and
give the resulting bytes to `component(...)`.

## Contract

The source of truth is
[`crates/brain-loophost/wit/agentloop/agentloop.wit`](https://github.com/aexhq/brain/blob/main/crates/brain-loophost/wit/agentloop/agentloop.wit).
The Component exports `turn` and imports five Brain services:

- `events(after)` reads a finite `EventPage`; continue from `next_cursor` for more history;
- `model` performs a model call;
- `dispatch` invokes one or more Tools;
- `emit` appends an extension Event and returns its committed sequence;
- `telemetry` publishes best-effort operational telemetry.

JSON strings on the WIT boundary use the generated session contract, also packaged as
`@aexhq/brain/contracts/session.json`. It includes `ModelRequest`, `ModelResult`, `ToolResult`, and `EventPage`. A turn receives
the current transcript, Agentloop slots, committed Events since its previous activation,
configuration, system prompt, Tool definitions, and a deterministic logical-time/seed envelope.
It returns the transcript, updated slots, and optional result.

Brain commits model, Tool, and emitted Event records. An Agentloop must not depend on the Wasm heap
surviving between activations; only returned transcript and slots are durable.

## Place the Component

```ts
import { agentloop, brainEnv, component } from "@aexhq/brain";
import { z } from "zod";

export const assistant = agentloop({
  options: z.object({ compactAt: z.number().min(0).max(1) }),
  implementation: component(new URL("./assistant.wasm", import.meta.url)),
  needs: ["https://models.example.com"],
});

const loop = assistant({ env: brainEnv({ name: "brain" }), compactAt: 0.8 });
```

`component(...)` also accepts `Uint8Array`, which is useful when bytes come from an object store or
another bundler:

```ts
import { readFile } from "node:fs/promises";

const bytes = new Uint8Array(await readFile("assistant.wasm"));
const assistant = agentloop({ implementation: component(bytes) });
```

The client sends the raw bytes to `POST /v1/agentloops`; Brain validates the Component contract and
returns its id, the SHA-256 of the bytes. Admission is cached for that `Component` object. Session
creation seals the id, parsed options, `needs`, and the Environment. The brain env runs the loop
with exactly the grants its needs name; an Environment reached over HTTP runs it however it
likes and reaches the same services through the turn routes it is handed with each turn.

## Effect semantics

The loop can request effects but does not perform Brain's model or Tool I/O itself. Brain durably
commits the intent, sends it once, and commits its known or unknown outcome before returning.
Propagate host-service errors unless the loop has an explicit policy for presenting them to the
model or user. Let the model or caller explicitly choose another attempt after seeing the failure or unknown
outcome. Brain never makes that choice automatically.

## Test it

Test policy outside Brain with fake host imports, then run the compiled Component through the real
Loophost. Include cases for parallel Tool calls, unknown outcomes, cancellation, invalid JSON,
restart between turns, and a fresh Wasm instance on every activation.

## Standalone reference

[`examples/reference-agentloop`](https://github.com/aexhq/brain/tree/main/examples/reference-agentloop)
builds a usable model-driving Component using only Brain's public types and WIT. It reads failure
observations into the transcript, dispatches requested Tools, and returns errors to the model.
It has no Aex dependency. Build with `cargo build --manifest-path examples/reference-agentloop/Cargo.toml --target wasm32-wasip2 --release`.

Read imports are available during an activation. They do not advance Brain's initial-page cursor;
keep an observation cursor in your own slot when consuming additional pages. Collect observations
before producing new effects so a loop does not chase its own Events indefinitely. Suspension
leaves external history reads available; it does not run guest callbacks.

Admission is explicit when desired: call `await brain.admit(placedLoop)` and
`await brain.admitTool(toolComponent)` before creation. Reuse those Component objects when placing
extensions; they cache successful admission. Brain retains compiled and prelinked templates,
never one session's credentials or heap.
