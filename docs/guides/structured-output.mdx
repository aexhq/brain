---
title: Get structured output
description: Ask for a validated JSON answer that your application can use.
---

Use structured output when your application needs data, such as a name and age, instead of
free-form text. Start with the [quickstart](/brain/docs/quickstart) and replace its send call:

```js
const person = await session.send("Ada is 37 years old. Extract her details.", {
  output: {
    type: z.object({ name: z.string(), age: z.number() }),
    maxRetries: 2,
  },
});
console.log(person);
```

With Pi or Codex, this returns a validated value such as `{ name: "Ada", age: 37 }`. TypeScript
infers the result type from the Zod schema. Keep the client connected until `send()` returns.

## Handle an invalid answer

The SDK can ask for up to two corrections after the first answer. Set `maxRetries: 0` to validate
only once. If corrections run out, it throws `StructuredOutputError` with the attempts, last
output and validation issues. Provider failures are not formatting retries.

Corrections are ordinary turns and can use the session's tools. Use one caller for the session
during this operation. Raw attempts remain in history, even when validation rejects them.

## Validate on the server

For work submitted from a short-lived request, configure output on the loop instead:

```js
const loop = pi({
  env: brainEnv({ name: "brain" }),
  output: {
    schema: z.toJSONSchema(z.object({ answer: z.string() })),
    maxCorrections: 2,
  },
});
```

Pass `loop` as `agentloop` when creating the session, then use `session.submit(...)`. Pi or Codex
validates and corrects the answer within the hosted turn. Corrections cannot call more tools.
Read session events for the final result; the submitting client need not stay connected unless
it hosts tools. Local Zod refinements are not part of JSON Schema.

The [structured-output reference](/brain/docs/reference/structured-output) describes SDK
validation, errors, cancellation and idempotency. The official
[loop packages](https://github.com/aexhq/extensions) document hosted output options.
