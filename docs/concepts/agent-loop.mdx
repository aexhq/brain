---
title: Agent harnesses
description: Choose an upstream agent at server startup, or implement Brain's harness interface.
---

An agent harness decides when to call the model, use tools, and compact a conversation.
Brain can run the real Pi, Codex, or OpenCode implementation behind one session API.
The upstream agent owns its behavior and native state; Brain executes and journals its
model and tool requests.

## Choose at startup

The Brain image includes all three adapters. Select one when starting the server:

```sh
docker run --rm -p 127.0.0.1:8080:8080 \
  -e BRAIN_API_TOKEN=quickstart \
  -e 'BRAIN_HARNESS={"command":"brain-harness-pi"}' \
  -v brain-data:/var/lib/brain ghcr.io/aexhq/brain:latest
```

Use `brain-harness-codex` or `brain-harness-opencode` for the other implementations.
One deployment uses one harness. Applications choose models and tools when creating
sessions; they cannot upload or replace the agent implementation.

| Adapter | Upstream | Runtime | Native state |
| --- | --- | --- | --- |
| Pi | Pi coding-agent SDK 1.2.0 | Node 22.19+ | Session JSONL |
| Codex | Codex app-server 0.162.1 | Rust executable | Rollout files |
| OpenCode | OpenCode SDK 2.0.28 | Bun 1.3.14 | SQLite |

Compaction runs inside the upstream agent and uses Brain's model adapter. Upstream
built-in tools, ambient extensions, direct model connections, and transport retries
are disabled or excluded. Only session tools are offered to the model.

## Configure a session

```ts
const session = await brain.sessions.create({
  model: { provider: "openai", name: "gpt-5-mini", apiKey },
  tools: [lookupOrder()],
  harness: { configuration: { contextWindow: 128_000 } },
});
```

Options depend on the selected adapter. Unknown options fail when the harness starts
the session. See the [harness reference](/brain/docs/reference/agentloop-contract).

Successful sessions resume from upstream native state. Back up the entire Brain data
directory, including `harness/`. The transcript API is a view of model context, not a
portable agent checkpoint. An interrupted or failed native activation requires a new
session: Brain will not let upstream recovery replay uncertain effects.

Pi supports HTTPS image and PDF inputs and tool media. Codex and OpenCode currently
support text only and reject imported transcripts. All three require fixed tool
placements for a native session; custom harnesses can implement dynamic discovery.

## Provide your own

The public boundary is JSON-RPC over stdio, so an implementation can use any language.
The TypeScript authoring API supplies typed lifecycle and callback functions.
[Write a harness](/brain/docs/guides/write-a-loop) starts with a complete example.
