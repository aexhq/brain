title: Agent loops
description: Choose the logic that calls the model, uses tools and manages the conversation.
---

An agent loop is the agent's decision-maker. It picks what the model sees, when to call tools and
when the answer is done. Brain runs the loop and saves its progress. Use a ready-made loop or
write your own.

## Use a ready-made loop

The [quickstart](/brain/docs/quickstart) uses Pi:

```ts
import { pi } from "@aexhq/agentloop-pi";

const loop = pi();
```

Pass `loop` as `agentloop` when you create a session. Pi calls the model, runs tool calls in
parallel and summarizes older conversation when the context fills up. Tune it with options such
as `pi({ contextWindow: 64_000 })`. It runs in `brainEnv({ name: "brain" })` by default; pass
`{ env }` to choose another Environment.

Prefer a different style? Try the [Codex loop](https://github.com/aexhq/extensions/tree/main/packages/loop-codex).
Both are loops built for Brain, not the Pi or Codex applications themselves. Each package guide
lists its behavior and options.

## Customize behavior

Often a session's `system` prompt and the loop's options are enough. Write your own loop when you
need different context selection, tool sequencing or stopping rules. A loop can also react to
background tool results without waiting for a new user message.

[Write an agent loop](/brain/docs/guides/write-a-loop) walks through JavaScript, Rust and Python
examples, including the build. The [loop API](/brain/docs/reference/agentloop-contract) covers
saved state and model and tool calls.
