Brain runs AI agents and saves their conversations, tool results and progress. Your application
chooses a model, adds tools, and sends messages. You can follow the output as it arrives or come
back later to read the history.

Use Brain when you want to keep control of your agent's behavior without building session
storage, event streaming and lifecycle management yourself. Run the server on your infrastructure;
[Aex](/docs) provides hosting if you prefer a managed service.

<Callout type="warn">
Brain is in early preview. APIs may change before 1.0. A server restart preserves saved history,
but interrupted work fails and is not automatically retried.
</Callout>

## Start here

[Run your first agent](/brain/docs/quickstart) with Docker and JavaScript. The example gives
the agent a function that looks up an order and prints its answer.

## The pieces you choose

| Piece | What it means | Example |
| --- | --- | --- |
| [Model](/brain/docs/concepts/model) | The AI that generates responses | Your OpenAI or Anthropic model |
| [Tool](/brain/docs/concepts/tool) | A function the agent can call | Look up an order or search your data |
| [Agent loop](/brain/docs/concepts/agent-loop) | The logic that calls the model and tools | Use Pi, Codex, or your own loop |
| [Environment](/brain/docs/concepts/environment) | Where that code runs | Your app, Brain, or a sandbox |

A [session](/brain/docs/concepts/sessions) brings these together for one conversation.
Start with a ready-made loop and add your own tools; you can replace more pieces as needed.
