## Build agents your way. Run their tools wherever the work lives.

Brain is an open-source agent runtime. You choose the agent loop, the model, the tools and where
each one runs. Brain saves the session and gives your application one API to drive it.

Picture a support agent that looks up an order in your backend, checks a delivery page in a
browser and updates a ticket. Each tool runs where it can reach what it needs, while your app
sends messages, follows progress and collects results from Brain.

## Run your first agent

The [quickstart](/brain/docs/quickstart) connects a model to an order lookup function in your app.
You need Docker, Node.js and a model key. Run Brain yourself, or let [Aex](/docs) host it.

## What you choose

| Piece | What it controls |
| --- | --- |
| [Agent loop](/brain/docs/concepts/agent-loop) | Context management, model calls and tool sequencing |
| [Model](/brain/docs/concepts/model) | The provider and model the session uses |
| [Tools](/brain/docs/concepts/tool) | The functions the agent can call |
| [Environments](/brain/docs/concepts/environment) | Where the loop and each tool run |

A [session](/brain/docs/concepts/sessions) ties these together for one conversation. Start with a
ready-made loop and your app's functions, then add browser or workspace extensions when you need them.

## Keep building

The application SDK supports TypeScript and JavaScript. Other clients can use the
[HTTP API](/brain/docs/reference/api). Each extension guide lists its supported languages.

<Callout type="warn">
Brain is in early preview, and APIs may change before 1.0. Saved history survives a server restart
when storage is intact, but interrupted work fails and is not resumed or retried.
</Callout>
