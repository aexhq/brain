# ADR-030: Replace pre-1.0 contracts and development data in place

- Decision date: 2026-09-04
- Status: Accepted
- Compiled: 2026-09-05

## Context

Brain was pre-launch without a stable contract or production-data migration commitment. Compatibility shims and multiple development formats would preserve abandoned designs and multiply verification work.

## Decision

Replace pre-1.0 contracts in place and rebuild consumers together. Keep the local marker brain-data/1; reject unknown formats and nonempty unmarked directories. Do not provide old-data migration or keep artificial v2 contract paths during this iteration.

## Alternatives considered

Versioning every development rewrite and supporting historical layouts costs code and tests for unsupported data. Silently guessing a layout would hide an invalid data directory.

## Consequences

Development data may need to be discarded explicitly by its owner; a /1 marker is not a compatibility promise across preview builds. The September 5 correction intentionally resets the proposed /2 name to /1. A stable v1 API remains roadmap work.
