# ADR-002: Execute replaceable Agentloops through an isolated step contract

- Decision date: 2026-08-21
- Status: Superseded
- Compiled: 2026-09-05

Superseded by: [ADR-023: Give the Agentloop one whole turn and asynchronous Brain services](2026-09-04-01-turn-services.md).

## Context

A built-in turn algorithm prevented independent Pi-like and Codex-like policies. Running arbitrary loop code in the server process would give it the server’s authority.

## Decision

At this stage, expose an Agentloop step/decision seam and execute supplied Wasm guests through Loophost. Bind the loop at session creation. Move official loop implementations to independently authored packages instead of privileged built-ins.

## Alternatives considered

A hard-coded loop made tool sequencing and compaction core policy. Unrestricted native callbacks did not supply an isolation boundary.

## Consequences

The extension boundary survived. The step protocol, resident loop state, and Brain-owned decision driver did not: [ADR-023: Give the Agentloop one whole turn and asynchronous Brain services](2026-09-04-01-turn-services.md) replaces them with one activation per turn and asynchronous services. The current native execution boundary is [ADR-034: Run native Components in a separate capability-restricted Wasmtime worker](2026-09-05-03-wasm-worker.md).
