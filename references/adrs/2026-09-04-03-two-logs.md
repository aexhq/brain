# ADR-025: Store transcript state and public Events in two per-session logs

- Decision date: 2026-09-04
- Status: Superseded
- Compiled: 2026-09-05

Superseded by: [ADR-032: Use one canonical journal and commit before exposing records or effects](2026-09-05-01-canonical-journal.md).

## Context

The session needed recoverable transcript and loop state, and the user wanted append-only writes rather than replacing complete snapshots. Public events and private transcript/state were being treated as distinct persistence streams.

## Decision

The September 4 implementation used one directory per session, an events log and a transcript/slots journal, one sequence across both, and one process-wide writer. Periodic full checkpoints bounded replay, with per-session backlog admission.

## Alternatives considered

A shared cross-session segment log complicated reclamation. A separate mutable state file duplicated a write path. Two logs made the public/private distinction explicit but duplicated ordering and recovery mechanics.

## Consequences

[ADR-032: Use one canonical journal and commit before exposing records or effects](2026-09-05-01-canonical-journal.md) replaces both logs with one canonical journal and derived public Events. [ADR-037: Release execution at turn boundaries and prepare artifacts before creation](2026-09-05-06-ephemeral.md) later adds a disposable reopen checkpoint; that checkpoint is not the old second canonical log or a mandatory recovery snapshot.
