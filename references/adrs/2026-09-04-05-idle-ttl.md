# ADR-027: Suspend idle session actors after an idle TTL

- Decision date: 2026-09-04
- Status: Superseded
- Compiled: 2026-09-05

Superseded by: [ADR-037: Release execution at turn boundaries and prepare artifacts before creation](2026-09-05-06-ephemeral.md).

## Context

Idle conversations kept actor tasks and history state in memory, and startup eagerly reconstructed sessions that might never receive another request.

## Decision

Introduce an idle TTL that drops the session actor after writes drain, emits suspension/resumption records, and rebuilds on demand. Keep ending distinct: only end detaches Environments.

## Alternatives considered

Retaining every session indefinitely charges idle conversations against memory. Rebuilding all sessions at boot makes readiness depend on the accumulated data directory.

## Consequences

[ADR-037: Release execution at turn boundaries and prepare artifacts before creation](2026-09-05-06-ephemeral.md) changes the default to releasing execution at create/turn completion, with TTL as an explicit warm-retention choice. Explicit zero disables automatic suspension. The independent Environment lifecycle survives this change.
