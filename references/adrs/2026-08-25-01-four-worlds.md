# ADR-004: Route all four extension kinds through Component worlds

- Decision date: 2026-08-25
- Status: Superseded
- Compiled: 2026-09-05

Superseded by: [ADR-005: Keep WIT Components and use Wasmtime for the native runtime](2026-08-26-01-runtime-choice.md).

## Context

The architecture reset sought one uniform extension system for Agentloops, Models, Tools, and Environments, without privileged official implementations.

## Decision

The reset implemented four Component worlds, immutable component declarations, bounded workers, and scoped host capabilities. It attempted to make all four extension kinds follow the same executable packaging path.

## Alternatives considered

Separate mechanisms for every official integration were rejected as a source of special cases. A universal Component pipeline offered uniformity but also imposed Component hosting where a transport adapter or resident function was sufficient.

## Consequences

The four responsibilities remain useful vocabulary, but current Brain does not require every Model or Environment adapter to be a Component. [ADR-005: Keep WIT Components and use Wasmtime for the native runtime](2026-08-26-01-runtime-choice.md), [ADR-012: Store provider-neutral messages and normalize model transports](2026-08-30-01-provider-model.md), [ADR-022: Let Environments execute implementations using their own platform APIs](2026-09-02-05-resources.md), and [ADR-033: Distinguish resident Tools from explicitly placed extensions](2026-09-05-02-placement.md) narrow the executable boundary. Do not infer current support from the old four-world contract.
