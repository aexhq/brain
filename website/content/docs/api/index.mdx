The endpoint pages are generated from Brain's Go route declarations and wire types. Download the [OpenAPI document](/openapi.json) for your own tooling.

## Requests

The local default is `http://127.0.0.1:8080`. Send Bearer authentication on session and catalog requests and `Content-Type: application/json` for request bodies. Unknown JSON fields and trailing JSON data are rejected.

Brain uses unversioned routes. The OpenAPI document's `current` metadata is not a compatibility guarantee. Pin the server, runner, and SDK artifacts together.

## Pagination and streaming

List endpoints accept `limit` from 1 to 1000, defaulting to 100. For session lists, `after` is the final session ID from the previous page. For event history, use `next_cursor` or the last durable event's opaque `cursor`.

Select SSE with `Accept: text/event-stream`. Reconnect using `after` or `Last-Event-ID`; the query takes precedence. Streaming replays retained history and then follows live output. See [events](/docs/reference/events) and [errors](/docs/reference/errors).
