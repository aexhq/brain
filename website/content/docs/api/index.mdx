## Making requests

The local server listens on `http://127.0.0.1:8080` by default. Send Bearer authentication on session and catalog requests and `Content-Type: application/json` for request bodies. Unknown JSON fields and trailing JSON data are rejected.

## Pagination and streaming

- **Pagination:** List endpoints accept `limit` (`1`–`1000`, default `100`). Pass the last session ID as `after` on `GET /sessions`, or pass `next_cursor` (or the last retained event's `cursor`) as `after` on `GET /sessions/{id}/events`.
- **SSE streaming:** Send `Accept: text/event-stream` to `GET /sessions/{id}/events` to replay retained history and stream live events. To resume after a disconnect, pass `?after=CURSOR` or `Last-Event-ID: CURSOR` (`after` takes precedence). See [Events & streaming](/docs/reference/events) and [Errors](/docs/reference/errors).
