## Prerequisites

Install **Go 1.26+** and **Node.js 24+**, and grab an API key for your model provider (this guide uses OpenAI). You also need Python 3.11+ if you plan to use the Python SDK or run the full test suite.

Clone the repository and build the Pi runner:

```sh
git clone --branch successor https://github.com/aexhq/brain.git
cd brain
npm --prefix runners/pi ci --ignore-scripts
npm --prefix runners/pi run build
```

## 1. Start Brain

Set `BRAIN_API_KEY` (at least 24 random bytes) and `OPENAI_API_KEY`, then start the server:

```powershell
$env:BRAIN_API_KEY = "replace-with-a-random-token-of-at-least-24-bytes"
$env:OPENAI_API_KEY = "your-provider-key"
go run ./cmd/brain -config examples/local.json
```

On macOS or Linux, use `export BRAIN_API_KEY=...` and `export OPENAI_API_KEY=...`.

With `examples/local.json`, Brain listens on `http://127.0.0.1:8080` and writes local state to `.brain/`. To customize your setup without touching tracked files, copy `examples/local.json` to `brain.json` (gitignored).

## 2. Run a session with the SDK

In a second terminal, set the same `BRAIN_API_KEY`, build the TypeScript client, and run the example script:

```powershell
$env:BRAIN_API_KEY = "replace-with-a-random-token-of-at-least-24-bytes"
npm --prefix sdks/typescript ci --ignore-scripts
npm --prefix sdks/typescript run build
node examples/session.mjs "Explain what makes a good agent tool."
```

This creates a Pi session using `openai/gpt-4.1-mini`, sends your prompt, and streams the response. See [Models & providers](/docs/reference/models) to use a different model.

## Or call the HTTP API directly

Create a session:

```sh
curl http://127.0.0.1:8080/sessions \
  -H "Authorization: Bearer $BRAIN_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"harness":"pi","config":{"model":"openai/gpt-4.1-mini","tools":[]}}'
```

Then send a message using the returned session `id`:

```sh
curl http://127.0.0.1:8080/sessions/SESSION_ID/events \
  -H "Authorization: Bearer $BRAIN_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"type":"user.message","text":"Hello","key":"first-message"}'
```

`POST /sessions/{id}/events` returns `202 Accepted` once the message is saved and queued. Stream or poll `GET /sessions/{id}/events` to read the assistant's reply—see [Events & streaming](/docs/reference/events).
