## Prerequisites

Install **Go 1.26+** and **Node.js 24+**, and obtain an API key for your model provider. This example uses OpenAI. Python 3.11+ is needed for the Python client and repository checks.

The current implementation is on `successor` while the repository transition is in progress:

```sh
git clone --branch successor https://github.com/aexhq/brain.git
cd brain
npm --prefix runners/pi ci --ignore-scripts
npm --prefix runners/pi run build
```

## Start Brain

In PowerShell, from the repository root:

```powershell
$env:BRAIN_API_KEY = "replace-with-a-random-token-of-at-least-24-bytes"
$env:OPENAI_API_KEY = "your-provider-key"
go run ./cmd/brain -config examples/local.json
```

On macOS or Linux, set the same variables with `export NAME="value"`, then run the Go command. Use distinct credentials for Brain and the model provider.

The example listens on `http://127.0.0.1:8080` and stores working state in `.brain`. Copy the configuration to the ignored `brain.json` file to customize it. Paths resolve from the process working directory.

## Run a session

In another terminal, set the same `BRAIN_API_KEY`, then:

```powershell
npm --prefix sdks/typescript ci --ignore-scripts
npm --prefix sdks/typescript run build
node examples/session.mjs "Explain what makes a good agent tool."
```

The example creates a Pi session, submits a message, and observes execution. It uses `openai/gpt-4.1-mini` by default. See [model configuration](/docs/reference/models) before choosing another model.

## Use HTTP directly

```sh
curl http://127.0.0.1:8080/sessions \
  -H "Authorization: Bearer $BRAIN_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"harness":"pi","config":{"model":"openai/gpt-4.1-mini","tools":[]}}'
```

Copy the returned `id`, then submit a message:

```sh
curl http://127.0.0.1:8080/sessions/SESSION_ID/events \
  -H "Authorization: Bearer $BRAIN_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"type":"user.message","text":"Hello","key":"first-message"}'
```

`202 Accepted` means the input was recorded locally. Read or stream [events](/docs/reference/events) for the response. Session configuration is frozen at creation. Resume and observation do not trigger inference.
