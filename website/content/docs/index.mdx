## A small core, by design

Brain handles sessions, tenant isolation, event transport, and persistence. The harness owns the model loop and context. Your tools run wherever they need to: another process, a sandbox, a browser, or a remote service.

<div className="brain-flow" aria-label="Your application sends requests to Brain, which coordinates a harness and external tools">

</div>

## Start local

The current implementation uses **Pi**, a Go server, and a thin TypeScript runner. TypeScript and Python clients expose the same session lifecycle. A local tool service demonstrates echo, scoped session inspection, and operator approvals.

<p className="brain-note">Brain is a local development preview. Codex, OpenCode, MCP, the broader tool catalog, and production capacity qualification are planned. S3/R2 adapters exist; live cloud qualification is still pending.</p>
