## How it works

Brain manages session state, tenant isolation, event streaming, and tool calls. The agent harness (currently **Pi**) runs the model loop and manages conversation context. Your tools run outside Brain in whatever environment they need—a separate service, a sandbox, a browser worker, or an internal API.
